# ReportNic - Paramedic Mobile App

![Project Status](https://img.shields.io/badge/Status-Archived%20/%20Prototype-red)
![Platform](https://img.shields.io/badge/Platform-Mobile-blue)

A mobile application prototype designed specifically for paramedics and first responders. This project was initially developed as an advanced prototype for **Hackathon Nicaragua 2024** to streamline emergency reporting and real-time dispatch communication. 

*Note: This specific repository represents an advanced, yet unfinished branch of the project before the main scope was pivoted during the hackathon.*

---

## Project Scope & Objectives

The primary goal of this mobile module was to provide emergency personnel with a fast, reliable tool in the field. 

- **Target Audience:** Paramedics, ambulance drivers, and emergency first responders.
- **Core Concept:** Rapid data entry for emergency reports, status updates, and critical patient information on the go.
- **Hackathon Context:** Built under a high-pressure, agile environment to demonstrate proof-of-concept mobile capabilities.

---

## Tech Stack

- **Frontend / Mobile Framework:** Flutter / Dart
- **Backend / Services:** Firebase Integration
- **Version Control:** Git & GitHub

---

## Project Status

This repository is currently **Archived / Inactive**. 
It remains available as a demonstration of mobile UI/UX prototyping, architecture planning, and rapid development methodologies applied during a hackathon. The main project direction was later shifted, and this specific mobile module was paused.
